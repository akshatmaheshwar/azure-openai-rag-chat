# IT Security Policy

*Larkspur & Finch Ltd. is a fictional company. This document is sample data for a demo.*

Effective date: 15 January 2026. Policy owner: IT Security Team.

## Passwords and sign-in

Passwords must be at least **14 characters** long. Passwords no longer expire on a schedule, but must be changed immediately if a compromise is suspected. Multi-factor authentication is mandatory for all accounts, using the company authenticator app. SMS codes are not accepted.

## Devices

Only company-managed laptops may access company data. Laptops lock automatically after **5 minutes** of inactivity. Full-disk encryption must remain enabled. Operating system security updates must be installed within **7 days** of release. Devices that fall more than **14 days** behind are blocked from the network until they are updated.

## Networks

The company VPN must be used on any network outside a Larkspur & Finch office, including home networks and public Wi-Fi.

## Reporting incidents

Lost or stolen devices must be reported to the IT Security Team within **1 hour** of discovery by calling the security line on extension **4040** or emailing security@larkspurfinch.example. Suspected phishing emails should be reported using the "Report phishing" button in the mail client. Do not forward them.

## Data handling

Customer data must never be stored on USB drives. Files classified as **Confidential** may be shared externally only through the approved file-sharing service, and links expire after **30 days**. Generative AI tools may be used only if they appear on the approved tools list.

## Training

All employees must complete security awareness training within **14 days** of starting and repeat it every **12 months**. Phishing simulations are run **quarterly**.
